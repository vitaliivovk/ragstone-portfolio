# source_data

Corpus root for ingestion (see `pinecone-pipeline/`). In this portfolio copy the corpus is **local-only**: the client documents (contracts, price lists, internal procedures, employee handbook) are confidential and are not included.

To run the pipeline, place your own documents here using the folder layout described in `teams-bot/rag/folder_map_prompt.md` and `pinecone-pipeline/corpus_metadata.py`. Everything in this folder except this README is gitignored.
